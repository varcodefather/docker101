## Follow along

Install Git, Docker and Neovim, then clone this repository:

```bash
git clone https://github.com/varcodefather/docker101.git
cd docker101/01-first-containers/docker101
```

Read the [tutorial walkthrough](01-first-containers/README.md) before running commands. It includes installation pointers, expected results, exercises and cleanup. Files are references for the walkthrough; follow its edits in order to match the video.

Tested in a local Arch development VM. No AWS account needed. Browser addresses point to the machine running Docker. Keep the working directory named `docker101` so Compose project and cleanup names match the video.

Each tutorial gets its own numbered folder. New folders appear after their demos are tested.
